# Hamza Malik Portfolio

Create a world-class, modern, premium portfolio website for a Frontend Web Developer.

## Tech Stack

- Next.js 15 (App Router)

- React.js

- TypeScript

- Tailwind CSS

- Framer Motion

- Lucide React Icons

- Shadcn/UI Components

- Responsive Design

- Dark/Light Mode

- SEO Optimized

- Performance Optimized (90+ Lighthouse)

- Clean Folder Structure

- Component-Based Architecture

The website should look like something a Senior Frontend Engineer would use.

The design should feel premium, minimal, elegant, modern, and futuristic.

Use smooth animations but avoid anything distracting.

Use glassmorphism, soft shadows, gradients, subtle hover effects, and smooth page transitions.

The overall feel should be similar to portfolios from:

- Vercel

- Linear

- Stripe

- Framer

- Apple

- Raycast

- Background: #09090B

- Primary: #3B82F6

- Accent: #06B6D4

- Text: White & Gray

- Gradient Effects

Typography:

Use Inter or Geist Font.

Spacing should be clean with plenty of white space.
